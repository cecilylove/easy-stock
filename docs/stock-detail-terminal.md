# 个股行情工作台：专业软件交互参考与实现边界

## 参考资料

本页为 easy-stock 原创实现，不复制品牌资源、付费指标或客户端代码。参考专业行情软件公开说明中的通用信息架构和操作习惯：

- [同花顺远航版帮助中心（分时/K线、快捷键、买卖档位、L1/L2区别）](http://help.10jqka.com.cn/faq/front/1/search?searchkey=%E5%88%86%E6%97%B6)：图表滚轮缩放、↑↓放缩、F5切换分时/K线、F8周期、年K；五档与逐笔区分。
- [东方财富万科A行情页](https://quote.eastmoney.com/sz000002.html)：紧凑报价信息、图表周期/复权操作、右侧五档与统计信息。
- [华西证券通达信组合窗口操作指南](https://m.hx168.com.cn/article/87963ef4e7595355504dec28b032a1ec.html)：主图MA5/10/20/60、成交量副图、指标副图、右侧信息栏及图表平移/十字光标。
- [通达信官方在线说明书目录](https://www.tdx.com.cn/products/helpfile/tdxw/left.html)：用于核对公开功能分类；技术分析章节链接当前抓取不可用，具体交互以上述券商公开指南为参考。

## 当前已实现

- 搜索与行情头部收紧；宽屏左图右盘口，中小工作区盘口移到图下；专注图表可隐藏盘口。
- 分时固定当天交易时段，仅在来源量额可校验时显示真实均价线。东方财富集合竞价轨迹单独标为参考价，缺少有效数据时明确提示，不以开盘价伪造竞价。
- 5日、日/周/月/年K及5/15/30/60分钟蜡烛图；日K取最近240条，其余样本范围见 `frontend/src/lib/stock-detail.ts`，不宣称无限历史。
- 原创SVG主图MA5/10/20/60、VOL与MA5/10、MACD(12,26,9)及KDJ(9,3,3)。MA不足周期省略；KDJ前8点省略；EMA以加载的首个收盘价初始化，K/D初值50，与终端全历史/自定义参数可能不同。不作为买卖信号。
- 图内滚轮、↑↓或按钮缩放；左键拖动平移；←→时间光标贯穿主副图，Esc取消；End/“回到最新”恢复跟随最新窗口。F5/F8仅在个股工作区获得焦点时生效，输入框内不拦截。
- 查看历史时用时间锚保持位置，轮询不强制跳回最新；跟随最新时新增K线会自动推进。价格、量和指标范围仅在越界时扩展；用户放缩/平移重置范围。
- 日 K 悬浮显示上海交易日的量价信息，单击锁定、离开图表仍保留，Esc / 解锁恢复悬浮；“查看当日分时”或双击蜡烛打开独立历史分时弹窗。前后导航优先使用分钟来源返回的实际覆盖日期，尚无覆盖记录时以已加载日 K 日期作为查询入口。关窗保留主图窗口与题材筛选。
- 趋势题材个股图复用 `ProfessionalKLineChart`，窄栏默认 MA5/10/20 + VOL，MACD / KDJ 可展开，支持放大查看；指标与十字光标联动，缺少真实量额 / 换手等字段时显示 `--`。题材历史仍限已有日 K 样本，不随放大自动加载更多历史。
- 历史分时由 `/api/v1/quotes/intraday?symbol=&date=YYYY-MM-DD` 优先读取新浪官网历史月档案，按档案内真实日期筛选；使用原生昨收、价格、成交均价和逐点股数，不伪造 OHLC 或成交额。月档案失败时仅回退同一交易日的近期分钟样本，明确标记原因、部分覆盖和实际时段，不跨源 / 跨日拼接。失败且备用没有同日点时不覆盖已有同股同日快照，保留旧图并标陈旧；新档案成功明确缺日则保持无数据，不伪恢复旧图。弹窗展示有效时间点数与本次来源覆盖，不自动轮询、不含竞价；原始价格与复权日 K 口径不同。
- 新浪报价解析真实五档、当日累计成交量/额；服务器按股存储数量，UI五档显示手数（除以100）。缺字段不补盘口。旧/历史快照同时作用于报价、盘口和统计信息。
- 默认报价与来源默认 K 使用新浪优先，失败仅用支持周期的腾讯 none 备用；年 K 从同源月 K 聚合。日周月年明确前/后复权/不复权统一腾讯；自动+指定复权也走腾讯。东方财富K入口已退役，不再作为备用或页面选项。当前腾讯口径与历史报告中的东财同名 qfq/hfq 不保证等价，指定口径不静默回退，basis_id 改变会整图重载。腾讯支持已验证沪深板块日/周/月，科创原生量股、主板创业量手，归一股后UI统一除100为手；旧无单位记录仍兼容，未知不猜。年聚合与专业蜡烛图保留合法的零/负复权价，仅剔除非有限值和无效 OHLC 结构；分时成交价格须为正。单日详情分钟接口不支持显式复权，参数错误明确拒绝。

## 尚未实现及取数边界

- 本地报价仍是盘中可见时约5秒轮询，K线约60秒；不是交易所实时逐笔或Level-2。
- 没有逐笔成交、委托队列、逐笔方向、筹码分布、画线下单、券商交易，也不把分钟线标为成交明细。
- 腾讯指定复权可因接口不可用失败，不自动换口径；分钟 K 不提供明确来源/复权选择。竞价仍只有东财参考轨迹，同日旧点可标陈旧，失败明确unavailable；普通分钟分时、五档和开盘价不作为备用竞价轨迹。asof历史因子回溯尚未实现，不伪造。
- 去掉东财后，新浪分钟/5日请求失败时暂无分钟备用；腾讯股票只支持已核对沪深板块日/周/月及聚合年K，不保证北交所/未知前缀。两源历史日周月额/换手缺失不能作为流动性枯竭，研究质量明确标未确认；右侧新浪报价五档和当日量额不受影响。
- 源的价格/量单位与复权口径并非统一供应商协议；源切换和复权切换须重新加载/重算，不能跨口径合并。
- 分时价格与均价折线遇无点分钟断开，孤立的真实价格 / 有效均价点使用独立标记显示，不补造跨缺口连接。黄线优先使用字段掩码明确的来源原生当日均价；无原生均价时仅以可校验的量额累加，首段截断 / 中间缺点必须标“样本成交均价”，不能当作全日均价。
- 指标由已返回历史样本计算，更多历史、公式编辑、自定义参数、区间统计、多股叠加仍属于后续能力。
- 历史档案覆盖取决于新浪实际存档；不存在、停牌或来源不可用时明确无数据，绝不替换为当天。原始月档案时间网格为 09:30–11:30、13:00–15:00，午间 13:00 只有在无量且价格 / 均价重复时可无损去掉，保留真实 11:30 成交量。若回退近期分钟样本，首日可能截断，缺点会标部分；新浪近期样本尾盘 14:58 / 14:59 不强制存在，不等同逐笔完整。
