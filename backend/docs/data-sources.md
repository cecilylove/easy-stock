# 数据源与取数边界

本文记录当前运行事实。已实施的数据源架构、后续治理及迁移清单见 [架构改造方案](../../docs/data-source-architecture-plan.md) 和 [改造清单](../../docs/data-source-refactor-checklist.md)；方案不改变下述默认来源和回退行为。

重构后的来源、能力方法、实际业务入口、默认主备/合并及未完全拆分边界，完整对照见 [数据源使用清单](data-source-usage.md)。

“东方财富仅保留热榜”的后续目标及现有供应商替代接口/缺口见 [专项评估](../../docs/eastmoney-hot-only-assessment.md)；该迁移尚未实施，下文仍记录当前实际默认链路。

## 当前运行来源

默认运行使用东方财富、新浪、腾讯、短线侠 / 开盘啦、财联社、同花顺和中金所七家已实现来源。按功能选择主源、备用或融合，并非所有来源可以互相替代。公共接口自动使用，不引入用户 Token、付费权限或新的 Python 服务；历史报告的来源记录不改写、不删除。

| 来源 | 当前能力 | 使用逻辑 |
| --- | --- | --- |
| 东方财富 | 集合竞价、目录与概念映射、公司资料、资金补充、融资、龙虎榜、公告、研报、涨跌停/炸板池、热榜与期指 | 个股K、明确复权、指数快照/历史已退出业务链路；保留其余尚无可靠替代的能力，逐步迁移。公共接口无需 Cookie。 |
| 新浪财经 | 实时报价、五档盘口、分钟及日/周/月 K、资金榜、公司主营/简介、最新已披露财务 | 行情/资金与公司资料/财务主源；资料/财务失败或覆盖不足按独立路由整份回退东财，不跨来源拼字段。不能用默认K口径替代指定复权。 |
| 腾讯财经 | 市场指数及指数 K、沪深支持板块股票日/周/月 K 与明确来源复权、行业强度、行业成分股、美股行业 ETF | 同身份指数和行业优先；股票 K 为新浪后的备用，明确 none/qfq/hfq 统一使用腾讯。全球未覆盖项明确缺失，不冒充完整。 |
| 短线侠 / 开盘啦 | 题材榜、龙头、涨停/连板池、逐股题材归因 | 与行业趋势融合，涨停数据由东财补充。两次业务真实刷新至少间隔 5 分钟，持久缓存与闸门重启后仍有效。 |
| 财联社 | 市场快讯 | 按业务需求读取；没有其他已接入的快讯备用。 |
| 同花顺 | 个股研究人气榜、龙虎榜席位标签 | 与东财人气榜分别取数、生成共识；席位标签由独立 `BillboardLabelProvider` / `ths` 适配器读取指定日期公开页，`BillboardLabels` 路由默认同花顺；空路由禁用标签，不影响东财原始买卖明细。最多缓存32个日期页、12小时，属于平台分类，不代表监管确认身份。 |
| 中金所 CFFEX | 期指单日持仓、会员排名、四品种持仓共识 | 东财期指取数失败时独立回退交易所排名；单日快照不能冒充完整历史、价格或基差。 |

这些公共接口按功能自动使用，不需要凭据。免费和近期成功不代表长期稳定，来源目录也不是上游可用性承诺。Tushare、TradingView 尚无取数实现，不展示为当前来源；预留凭据入口已移除，历史 Tushare/THS/东财凭据字段仅保留兼容存储，不参与取数。

模型运行时、雪球/淘股吧复盘浏览器登录、微信本机文章服务在设置中独立管理，不加入公共来源计数。“无需凭据”不适用于这些模型或复盘采集入口。游资心法 GitHub、远程复盘清单和用户导入文章也不是行情备用供应商。

## 默认功能及回退边界

- 报价、盘口：新浪。个股 K 线默认新浪 → 腾讯不复权（仅已支持股票日/周/月）；单日分时与分钟线以各接口实际返回为准。五日图是 5 分钟采样，不是独立五日分时接口。年 K 从月 K 按自然年聚合。
- 显式 `adjust=none|qfq|hfq`：缺省与 `provider=tencent` 都统一为腾讯精确系列键；`provider=eastmoney` 入口退役返回 400，不静默重标供应商。`provider=tencent&adjust=source` 明确为腾讯 none；自动 source 与新浪只称来源默认未统一。三种明确复权失败不借新浪默认价格替代；同名复权与历史东财证据不保证因子/锚点等价，不改写历史报告。不支持分钟线明确来源/复权选择，`asof` 回溯不支持并拒绝。
- 股票 K 元数据记录实际 provider、instrument、requested/effective adjustment、basis_id、period、time_zone、volume_unit 和行级字段掩码。日周月日期按上海交易日，腾讯主板/创业板原生量为手而科创原生量为股，适配器分别归一为股；有效原生快照量额证据若矛盾则拒绝。未知市场/前缀不宣称支持；年 K 从同源同口径同单位月 K 聚合，年度缺昨收或换手率不补造。
- 盘前竞价：东方财富参考轨迹，没有独立备用。失败可保留同股同日旧参考点并标记陈旧，不推造参考价格。
- 指数：快照和日/周/月历史只请求腾讯，不再请求东方财富补缺；NDX 为 `nasdaq100`、IXIC 为 `nasdaq_composite`，旧 `nasdaq` 始终兼容 NDX。正常、空结果和失败场景都不触发东财，只有同参数旧快照可陈旧兜底。不支持指数分钟/年K或未适配ID时提前明确拒绝，weekly/monthly/101/102/103兼容为日周月。全球目录5项（nikkei/kospi/taiwan/dax/cac）明确 partial/missing_ids；腾讯其他缺项也显示缺失。海外快照时间偏移未确认时保留 native_timestamp、time_zone=unknown，不假定纽约或宿主时区。UI与AI将未知/Go零时间显示为未知，原生时间仅注明偏移未确认；日周月交易日期按标签显示，不随宿主时区移日。
- 研究基准/日历：`000001.SH/000300.SH/000016.SH/000852.SH/000688.SH/399001.SZ/399006.SZ` 专用映射到腾讯指数历史备用，返回symbol还原研究符号、instrument_id保留canonical指数身份、成交量标provider_index_volume。未知/北证50暂不声称腾讯支持，不放宽股票适配前缀冒充指数。
- 行业强度：腾讯优先、东财有效字段回退；行业原生成分：腾讯。industry/fusion 的 provider/native_code/dimension 明确存入身份，东财 BK 不直接传腾讯，旧 ID 仅真正缺字段时允许兼容推断。纯行业和融合共用成员路由。腾讯成员上限 500，返回 total/returned/complete/has_more，不把 topN 当全集；目录相关候选及开盘啦领涨另组，不污染原生成分。
- 资金榜：新浪优先、东财有效字段回退。新浪板块总净额与东财主力净额不等价，页面明确列名；bkzj 只有主力资金时不冒充强度或分单，requested/effective sort 表示排序降级。数值字段按行 FieldsKnown/AvailableFields 区分缺失与有效 0，UI、评分和 AI 证据共用限制。排序只需存在至少一行有效数值，缺失沉底；列表字段交集不覆盖行级可用性。正常行业派生score仅当公式所有输入有效时声明，真实零输入仍可计算；资金-only降级不声明score，筛选不得变更总额/主力统一口径。
- 趋势题材：融合行业与开盘啦有效题材，并使用东财概念映射和成分补充；缺一方时使用其余有效结果。开盘啦旧题材按交易日衰减，超过两个交易日不参与融合。
- 涨停/连板：开盘啦持久服务启用时优先使用其数据，由东方财富补充或回退；无持久服务时使用东财池。新采集带字段有效性，合并不以0判缺失；补值带 `field_sources/field_fetched_at`，默认来源保留原事件。History/ProgressiveHistory可选契约独立携带请求/覆盖/缺失日期，Access透传；合法空日是0事件而不是缺日，普通/渐进梯队只比较相邻且覆盖的交易日，情绪保留成功空日。失败日携带typed覆盖错误/partial，不能因部分日期有数据就声明完整；旧事件-only供应商只能证明实际事件日期，不能推导空日。未知板数单列未知组、不冒首板或计算晋级；缺成交额/开板次数不显示有效零合计。情绪新增严格字段校验，必要事件输入未取得时不更新评分。
- 主营/公司简介：新浪公开公司资料表主源，校验公司名、代码与上市市场，主营与简介均需明确；行业/经营范围不冒充主营。财务：新浪结构化合并累计/CNY主源，按最新已披露报告期，普通/银行字段键和同比比例分别归一，银行毛利率标不适用。缺报告披露日期不静默选旧季度，资料更新时间未知不伪造。
- 公司资料/财务通过 `Business/Fundamentals` 与各自 `BusinessFallback/FundamentalsFallback`（默认东财）独立装配，共用10秒父预算，每次最多6秒并预留备用时间；主源完整不请求备用。覆盖不足整份回退，不跨来源或报告期补字段，备用报告旧于有效主源则不替换；备用失败可保留主源有效部分并显式partial。空备用路由禁用，不自动恢复。
- 财务带 `fields_known/available_fields`，金额与同比独立有效；分析另带 `score_available/published_at/fallback_reason/not_applicable_fields`，无评分输入不参与普通/新股评分，缺失指标显示未知，披露晚于研究截止时不纳入证据或评分基线。此日期只有日粒度，仍不是完整历史PIT/修订财报库。旧未标记历史数据保留兼容，不重写。
- 第二批公告/研报主路由为新浪→东方财富整份查询备用：个股公告按自身股票/市场身份解析最多4页、100项，正文3并发/8000字；公司/行业研报近45日最多5页，最多8条正文/3并发，平台可读文本不等于PDF全文。不执行JS、不借登录态。全市场公告CompanyCode身份映射未验、指定行业分类检索口径不等价，明确Unsupported并回退东财，不能宣称这两项已去东财。
- `QueryCoverage=complete|bounded|unsupported`描述请求latest-N/过滤窗口，与正文partial独立；列表不完整或上游失败整份回退，正文缺失仅列项降级。主备共用18秒父预算，各次最多12秒、预留备用最多6秒，适配器本身10秒。取消不回退，空备用路由禁用。研报评级/EPS/目标价/PE无结构化字段时不从自由文字推值，前端显示来源/内容范围，研究透传覆盖限制。
- 目录、融资余额和原始龙虎榜仍是东方财富默认专属接口；本批没有迁移这些能力。
- 融资按 SCDM 保留沪/深/京覆盖集合；未知身份、重复市场拒绝，缺失字段不按0汇总。只有相邻交易日完整市场且余额字段有效才计算日变化；部分覆盖可展示但不画成全市场趋势、不输入AI为全市场变化。龙虎榜 `BUY_SEAT/SELL_SEAT` 原生编码不解释为数量，明细加载后按实际返回数组计数。
- 公告列表与正文共用10秒父预算，最多100项、正文并发最多4；`content_status/content_scope/content_issue` 区分可读正文、列表-only及8000字截断。正文缺失不否定有效列表，但研究证据明确不是阅读全文。
- 人气榜：同花顺与东方财富榜单分别取数，单方失败时保留另一方，双源共识以真实返回为准；全失败时可保留旧榜并标记陈旧。
- 期指：东方财富主力目录与历史持仓，失败回退中金所最近交易日单日快照；会员排名与共识以返回来源为准，回退后可能缺价格、基差和历史序列。

同一图表不会合并不同来源、交易日或复权口径的价格历史。历史报告可以保留原始东财来源，不能冒充本次新采集结果。

日 K 的历史分时入口（`/api/v1/quotes/intraday?symbol=&date=YYYY-MM-DD`）优先读取新浪官网 `realstock/company/{symbol}/hisdata/{year}/{month}.js` 月档案，安全抽取压缩数据并独立解码，校验每个交易日原生日期、昨收、价格、均价和量。不执行远端 JavaScript，不新增 Python / Node 运行时或供应商。月档案按股 / 月有界缓存和请求合并，页面返回所选日实际时间点与档案覆盖日期。历史档案失败时可回退该日最近分钟样本，明确原因与 partial / unavailable；若备用缺少同日点，则保留同股同日已有缓存并标陈旧，无缓存时返回结构化不可用。成功档案明确缺日不以旧图伪恢复；404 / NoData / Invalid 仅记录标的级诊断，429 / 5xx / 超时仍为能力故障；无数据不替换为当天，不恢复退役东财 K 线。原生逐点成交量为股，不反推 amount；原生 average_price 有独立字段掩码。没有原生均价的截断样本累计值只能称样本均价。

## 缓存、刷新及失败处理

市场模块成功数据缓存 45 秒；刷新失败可返回本次服务运行中已有成功快照并标记陈旧，无快照则明确报错。研究任务的直接证据采集不等于这些 HTTP 模块缓存。行业/资金主备共用10秒总预算，主源最多7秒且按剩余预算预留约1/3、最多3秒给备用；子预算过期即使适配器返回nil错误也不算成功。

东财JSON GET只有适配器一处重试，包含首次最多3次；有限指数退避与抖动，400/401/403、无效JSON不盲重试；429尊重Retry-After与同origin冷却，等待受父取消/截止约束。错误保留类型、HTTP状态与原因链，超时和取消分开；其它遗留协议的全量类型迁移仍是后续项。

个股详情报价和单日分时按股票、周期及上海日期隔离，成功复用至少 5 秒，同键合并在途请求；失败退避 30–120 秒，并可返回同股同日最近成功快照。取消最后一个查看者时取消上游请求。默认与严格 K 路由按来源/市场/周期/调整模式隔离网络与服务失败退避，连续两次 EOF/超时/429/5xx 等失败后 30–120 秒绕过；已完成但标的无数据/缺指定系列/字段无效仅记录 symbol 范围，不熔断同市场其他股票、不降级全源。标的记录按每来源128条及10分钟保留上限；仅真实尝试记观测，取消和不支持能力不算失败。普通日/周/月 K 没有统一服务端旧快照兜底；前端已有图表刷新失败时保留旧图并提示。

股票目录默认使用东方财富，包含名称及其实际返回的行业 / 概念归属。成功缓存 6 小时、同键合并请求；失败可标记陈旧并返回已有目录，无缓存时明确报错。缓存和合并读取不更新来源观测。

详情在工作日盘中且页面可见时后台刷新：报价、分时约每 5 秒，五日及日/周/月/年 K 约每 60 秒。午休、收盘后、周末及隐藏页面暂停；节假日仍以来源数据时间判断。刷新期间不切回加载占位，慢请求不重叠，切换股票/周期拒绝旧响应；图表保持历史窗口和非收缩坐标。分时固定上午/下午交易时轴，未来区域留空，量额不足不显示伪造均价线。专业图表边界见 `docs/stock-detail-terminal.md`。

开盘啦持久缓存的读取不代表真实访问上游；5 分钟是业务最小请求间隔，不是后台定时探测。人气榜成功缓存 2 分钟，失败可以保留旧榜并标记陈旧。持久渐进快照可在重启后恢复并标记陈旧；用户数据库与历史报告不删除。

## 设置中的来源观测

来源清单与最近请求记录集中在系统设置的“行情与内容数据源”。每家展示实际能力、请求时间、最近成功/失败和作用问号说明；问号支持鼠标悬浮与键盘聚焦。业务工作台不再展示全局可用分数，保留本模块的实际来源、来源时间、陈旧与错误说明，以及直达设置的入口。

`GET /api/v1/sources` 仅读取本次服务运行的业务观测与最近手动检测结果，不主动请求供应商。打开设置立即读取，页面可见时约每 30 秒读取，关闭或切换后端取消旧请求；读取失败保留旧记录并说明未更新。这些记录不是可保存的本机设置，不能写入 `PUT /settings`。

“刷新检测”按钮调用 `POST /api/v1/sources/check`，默认实际请求七家公共来源的代表接口；自定义装配按启用的注册探针范围执行；点击立即显示“检测中”，完成后逐源展示本轮可用/失败、检测时间、用途、耗时及说明。按钮检测与业务观测独立记录，不能用一个代表接口成功覆盖该来源的其他业务故障，也不能把设置接口请求失败当成七家供应商失败。重复点击不重复启动同一轮在途检测。

检测范围为东方财富股票目录（每次新客户端直接请求，防上轮catalog缓存冒充）、新浪个股报价、腾讯代表指数、财联社快讯、同花顺人气榜、开盘啦涨停池、中金所 IF 最近交易日持仓快照。每家检测直接访问对应来源，不通过双源榜单或期指主源替另一家报成功，也不以网站首页可访问或业务缓存命中作为成功证据。休市期间有效的最近交易日数据仍可验证接口，不要求当日有成交或排名。检测成功只证明本轮代表接口返回有效内容，不保证该来源全部功能正常。结果保留原检测时间，超过 10 分钟显示过期，服务重启清空；仅提供手动主动检测，未增加后台定时探测。

业务观测仍以供应商为单位：`available` 表示最近被记录的实际请求成功，`degraded` 表示最近失败或部分失败，`unknown` 表示无记录或记录超过 10 分钟；没有记录时显示“暂无业务观测”，避免与按钮主动检测混淆。`checked_at`、`last_success`、`last_failure` 不因缓存读取续期，服务重启清空。某家一个接口成功不代表所有接口正常；价格、指数、行业和资金的新链路额外记录能力级 capabilities，设置可展开查看某能力的最近失败/成功，不会因另一接口成功抹除其失败；该能力记录仍有覆盖边界，不能根据供应商总状态推算未记录能力。

默认报价、K 线、股票目录、财联社快讯、普通/渐进题材、总览刷新、热榜和期指会记录可归因的实际结果；取消请求不记来源故障。失败与备用来源成功分别记录；不支持的指数/周期与尚未实现能力不冒充某家请求失败。组合结果无法可靠归因的失败保留功能错误，不猜某家故障。新THS标签链路显式返回 `execution_state=fetched|cache|joined|skipped`，健康追踪不把缓存、共享等待和未尝试记为新上游成功/失败；共享请求仅最后查看者退出才取消。该执行状态不是所有供应商已迁移，东财重试各次网络Attempt尚未统一入观测。部分直接取数路径仍有观测覆盖边界，“无记录”不能断言绝未请求过。

## 架构接入与来源目录

单源能力在 `internal/datasource/contracts` 定义；默认实现与 Routes 在 `assembly` 登记，访问/多源策略在 `service`，供应商协议仍在 `providers`。注册目录是启动时不可变配置，尚无运行中热切换或设置路由编辑器。具备实现的注册项由实际槽位生成canonical能力名，输入旧别名仍显式兼容，但虚报/typed-nil实现不能激活路由；描述-only历史目录只作兼容，不是可调用实现。新增已有能力需实现适配器、注册槽位、配置路由并验证语义；移除来源需同步调整相关路由，启动校验拒绝悬空、禁用和未实现能力。东方财富退役价格/指数路由仍被拒绝。

`GET /api/v1/sources` 与 `POST /api/v1/sources/check` 增加兼容字段 `catalog`，由后端公共和内容注册目录产生。默认内容目录包含雪球、淘股吧、公众号正文、预整理每日复盘、GitHub 知识；这些模式通过业务任务/登录状态诊断，不参加七家公共代表检测，登记不代表授权已就绪。新注册来源可自行提供独立探针；空检测范围、禁用和未实现来源不进入本轮检测。

`Config.DataSources` / `DataSourceRoutes` 及 `ContentSources` 是代码装配入口；供应商同时具有行情和资讯分类不必实现全部能力。业务仍使用原 API 与中立模型。旧快照、报告和来源身份不随路由更换重标；新题材快照保留并校验来源 ID/URL/交易日。普通业务源名若没有历史别名可显示实际 ID，设置清单使用后端描述名称。

题材原生代码只在所属供应商内解释；开盘啦私有码映射仅用于默认来源及旧快照，替换来源按名称匹配。题材强度缓存隔离来源身份；个股研究通过独立的 pool/leader 归因角色选择证据，历史未记录角色的数据保留原标签兼容。请求取消（含供应商主动返回的取消）不触发备用请求或失败观测；未启用能力不将其它已启用来源记为故障。

知识缓存清单保留 v4 兼容，同时记录来源 ID、集合 URL 和目录指纹。更换来源或重新绑定会验证目录与正文，不能只凭相同 Revision 复用旧来源；正文按内容哈希落盘，下载部分失败仍保留旧清单引用的实际正文。

详见 [当前架构](architecture.md) 与 [实施清单](../../docs/data-source-refactor-checklist.md)。现有场景缓存、适配器重试和持久刷新闸门保留唯一所有者；全量统一网络事件/错误治理是后续项，未记录能力不能推断健康。

## 验证原则

- 普通测试使用模拟上游；来源恢复的回归检查覆盖默认服务装配、真实回退规则、热榜与期指归属，以及七源主动检测。
- 公网测试显式启用，区分真实上游失败与代码回归，不能据几次成功宣称“稳定”。
- HTTP 成功可能来自缓存；请读取实际 `source`、来源时间、`stale` 和能力缺失说明。
- 保留许可证、历史证据来源和本机凭据，不用配置整理删除用户数据。
